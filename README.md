# Matchsticks Game Using Linked List in C++

## About the Project
This is a simple two-player Matchsticks Game developed using C++. The project uses a **Singly Linked List** to store and manage the matchsticks dynamically.

## Game Rules
- The game starts with 21 matchsticks.
- Two players take turns.
- Each player can pick 1 to 4 matchsticks per turn.
- The player who picks the last matchstick loses.
- The program displays the remaining matchsticks after every turn.

## Data Structure Used
**Singly Linked List**
